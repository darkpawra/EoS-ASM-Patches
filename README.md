# EoS-ASM-Patches
Here you will find all my publicly available ASM patches for Pokemon Mystery Dungeon: Explorer's of Sky!

Remember that you have to edit the .org values inside any overlay36 patches to place them in a spot that is free in your specific hack.

My patches are set up for use with US ROMs only. If you are on a US ROM, and the patch compatibility says 'Applied' before you apply it, it means you have already installed a patch that hooks the same address as one of mine.
