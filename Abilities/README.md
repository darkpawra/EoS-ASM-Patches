# Abilities
CursedBody: Implements the Cursed Body ability. Upon taking damage, gives a 30% chance to prevents the target from using the last move it used. The effect persists as long as the target remains on the floor. It uses ability ID 0xB0, summary text string 14090.

FriskBuff: Implements a buff to the Frisk ability. On top of what Frisk already does, when using regular attack on an enemy, it will also call the Scanner Orb effect, revealing all items on the dungeon floor.

Multitype + Natural Gift Buff: Implements the Multitype ability using Natural Gift's item table to change type. Buffs Natural Gift by remapping Joy Seed to Fairy type, and increasing all BPs. Uses ability ID 0xaa, summary Text String 14084.

Prankster: Adds the ability Prankster. When the Pokémon uses a status move, it uses it 2 times at once but only consumes PP for 1 use. The move won't work if the target is a Dark-type foe. It uses ability ID 0xad, summary text string 14087, feedback text string 16294.

UnseenFist: Implements the Unseen Fist ability, any damaging move this Pokemon uses will hit through the Protect status and end it early. It uses ability ID 0xAE, and the summary uses text string 14088. (The friend code has been registered.)
